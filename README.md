# 🦀 My Rustlings Journey

My personal solutions and progress tracker for [Rustlings](https://github.com/rust-lang/rustlings) — a collection of small exercises to get you used to reading and writing Rust code.

## 📖 About

This repo contains my solutions to the Rustlings exercises.

## 🛠️ Setup

```sh
# Install Rustlings
cargo install rustlings

# Initialization
rustlings init

# Moving into new directory
cd rustlings

# Opening the Editor that you are going to use
code .

# Starting Rustlings
rustlings run
```
